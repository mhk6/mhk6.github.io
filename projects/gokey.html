GoKey, a USB Security Key

Altium · STM32L4 · ATECC608B · USB-C

GoKey is a USB-C hardware security key, similar to a FIDO key. The idea is that you plug it in and press a button to prove you're physically there, instead of typing in a code from an app. I designed the board in Altium, released it for fabrication, and hand-assembled the first units.

Where the keys live

The main design decision was keeping the private keys out of the microcontroller's flash. They sit in an ATECC608B secure element instead, a tamper-resistant chip that generates ECC keys on board and will sign with them but never hand them back. The STM32L4 runs USB and asks the secure element to sign things. It never sees a key.

So reading out the STM32's flash gets you nothing, which is why commercial keys are built the same way.

Layout and assembly

Everything had to fit on a two-layer board about the size of a keyring. Most of the layout work went into the power and decoupling network, since that's what suffers first when the area runs out. I assembled the first units by hand, using hot-air reflow for the STM32L4's QFN package and micro-soldering for the USB-C connector.
